# FS25 Unused Mods

Finds downloaded mods that you aren't actually using in any of your savegames. When a savegame starts, it checks every savegame for owned vehicles, placeables, hand tools and items and lists the mods that have none. Maps, mods without store items, and script mods enabled in a savegame are ignored. The list, with each mod's file path, is written to the log (search for [UnusedMods]) and to modSettings/FS25_UnusedMods/unusedMods.xml.
